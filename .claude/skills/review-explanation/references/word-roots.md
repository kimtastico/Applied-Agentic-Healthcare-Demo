# Medical word roots

Each root gets only its own meaning. When a word combines roots, the full meaning comes from putting the parts together: "leuko" (white) + "cyt" (cell) + "osis" (condition or increase) = more white cells than normal. It is wrong to give one root the meaning of the whole word.

## Prefixes

| Root | Means |
| --- | --- |
| a-, an- | not, without |
| bi- | two (bilateral = on both sides) |
| brady- | slow |
| dys- | bad, hard, not working well |
| hyper- | above, too much |
| hypo- | below, too little |
| tachy- | fast |
| uni- | one |

## Suffixes

| Root | Means |
| --- | --- |
| -algia | pain |
| -ectasis | stretching out, widening, opening up |
| -ectomy | surgical removal |
| -itis | inflammation (swelling and irritation) |
| -megaly | bigger than normal |
| -osis | a condition, often an increase |
| -pathy | disease |
| -penia | too few, a shortage |

| -pnea | breathing (dyspnea = hard breathing) |
| -scopy | looking inside with a scope |
| -uria | in the urine |

## Units on lab reports

A unit explanation says what is being counted, never what a normal amount is.

| Unit | Means |
| --- | --- |
| mmol/L | millimoles per liter: how much of a substance is in a liter of blood |
| mg/dL | milligrams per deciliter: how much of a substance, by weight, is in a tenth of a liter of blood |
| mEq/L | milliequivalents per liter: how much of a charged mineral, like sodium or potassium, is in a liter of blood |
| g/dL | grams per deciliter: how many grams are in a tenth of a liter of blood |
| U/L, IU/L | units per liter: how active an enzyme is in a liter of blood |
| K/uL, x10^3/uL | thousands of cells in a microliter, a tiny drop of blood |

## Whole words that patients often see

| Word | Means |
| --- | --- |
| edema | swelling from extra fluid |
| effusion | fluid that has leaked out and collected |
| lesion | an area of tissue that looks different from normal |
| opacity | an area that looks whiter or cloudier on an X-ray or scan |
