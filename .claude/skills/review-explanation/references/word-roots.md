# Medical word roots

Each root gets only its own meaning. When a word combines roots, the full meaning comes from putting the parts together: "leuko" (white) + "cyt" (cell) + "osis" (condition or increase) = more white cells than normal. It is wrong to give one root the meaning of the whole word.

## Prefixes

| Root | Means |
| --- | --- |
| a-, an- | not, without |
| bi- | two (bilateral = on both sides) |
| brady- | slow |
| dys- | bad, hard, not working well |
| hyper- | above, too much |
| hypo- | below, too little |
| tachy- | fast |
| uni- | one |

## Units on lab reports

Each part of a unit is spelled out as its own word part, starting with its full name ("mmol/L" → "mmol" and "L"). A unit explanation says what is being counted, never what a normal amount is.

| Part | Means |
| --- | --- |
| mmol | millimoles: a very small amount, counted the way scientists count particles |
| mg | milligrams: a very small weight, one thousandth of a gram |
| mEq | milliequivalents: a very small amount of a charged mineral, like sodium or potassium |
| g | grams: a small weight (a paper clip weighs about one gram) |
| U, IU | units, international units: a measure of how active an enzyme is |
| K | thousands |
| L | liter: about a quart |
| dL | deciliter: one tenth of a liter |
| uL | microliter: a tiny drop |

## Whole words that patients often see

| Word | Means |
| --- | --- |
| edema | swelling from extra fluid |
| effusion | fluid that has leaked out and collected |
| lesion | an area of tissue that looks different from normal |
| opacity | an area that looks whiter or cloudier on an X-ray or scan |
